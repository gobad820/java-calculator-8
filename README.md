# java-calculator-precourse

## 구현 목록

- [X] 입출력 기능 추가
- [X] 구분자 기능 추가
    - [X] 쉼표 또는 콜론을 구분자로 가지는 문자열 입력 시 구분자를 기준으로 문자열의 분리
    - [X] 분리된 숫자의 합 기능 추가
- [X] 커스텀 구분자 지정 기능 추가
    - [X] "//"와 "\n"가 동시에 나왔을 때 탐지 기능 추가
    - [X] 탐지 후 그 사이 인덱스 저장 기능 추가
    - [X] 저장된 인덱스의 문자열을 구분자로 등록하는 기능 추가
- [X] 구분자와 양수로 구성된 문자열이 아닌 다른 문자열이 입력되었다면 `IllegalArgumentException` 발생 후 종료 기능 추가

### 리팩토링

- [X] 구분자 클래스 생성
    - [X] 구분자 리스트에 커스텀 구분자 삽입 메서드 추가
- [X] 변환자 클래스 생성
    - [x] 문자열 수식 리스트를 인티저 수식 리스트로 변환 메서드 추가
- [X] 파싱 클래스 생성
    - [X] 정규식을 이용한 커스텀 구분자 유무 여부 확인 후 커스텀 구분자 처리 후 문자열에서 제거 메서드
    - [X] 커스텀 구분자 추가 메서드 생성
    - [X] 구분자를 통한 문자열 분할 메서드 추가
- [X] 합계 클래스 생성
    - [X] 정수형 리스트 합계 값 리턴하는 메서드 추가
- [X] 검증 클래스 생성
    - [X] 입력 검증 메서드 추가
    - [X] 수식 필터링 메서드 추가
    - [X] 문자 검증 메서드 추가
