# java-calculator-precourse

## 구현 목록

[ ] 입출력 기능 추가
[ ] 구분자 기능 추가
    [ ] 쉼표 또는 콜론을 구분자로 가지는 문자열 입력 시 구분자를 기준으로 문자열의 분리
    [ ] 분리된 숫자의 합 기능 추가
[ ] 커스텀 구분자 지정 기능 추가
    [ ] "//"와 "\n"가 동시에 나왔을 때 탐지 기능 추가
    [ ] 탐지 후 그 사이 인덱스 저장 기능 추가
    [ ] 저장된 인덱스의 문자열을 구분자로 등록하는 기능 추가
[ ] 구분자와 양수로 구성된 문자열이 아닌 다른 문자열이 입력되었다면 `IllegalArgumentException` 발생 후 종료 기능 추가
